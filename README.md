# Apex Finance — Automation & Promotion Workflow
**Prepared by: Sagar Dhawan**

A student project demonstrating a finance marketing workflow using Canva, Google Drive, Zapier, Gmail, Excel and Power BI.

## Files
- `Apex_Finance_Project_Report_Sagar_Dhawan.pdf` — shareable project report
- `Apex_Finance_Project_Report_Sagar_Dhawan.docx` — editable report
- `Apex_Finance_Presentation_Sagar_Dhawan.pptx` — presentation
- `Apex_Finance_Analytics.xlsx` — data and summary sheets
- `Apex_Finance_Sales_Dataset.csv` — Power BI import file
- `Power_BI_Dashboard_Guide.md` — dashboard build steps
- `assets/` — poster, charts and workflow diagram

## Workflow
Canva export/webhook → Zapier trigger → Google Drive storage → Gmail notification. Import the sales CSV separately into Power BI for analytics.

## Important
All transactions are synthetic and created for demonstration. This package does not connect to or activate your Canva, Drive, Zapier, Gmail or Power BI accounts. Do not present sample records as real business results. Financial promotions require appropriate review and disclosures.
