## Publish this website with GitHub Pages

1. Open https://github.com/sagardhawan443/Apex-Finance-Automation-Workflow
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `Apex_Finance_Promo_Poster.png` to the repository's **main/root** folder.
4. Commit the changes.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. Your website address should be:
   https://sagardhawan443.github.io/Apex-Finance-Automation-Workflow/

The website links to the existing project files in the repository, so keep those files in the root folder with their current filenames.

## Notes
- This is a static website; it does not connect to or activate Canva, Zapier, Google Drive, Gmail or Power BI.
- The sample dataset is synthetic and for demonstration only.
- The website uses Google Fonts when internet access is available; it falls back to system fonts otherwise.
