01 — THE IDEA

Bringing the moving parts
into one clear flow.

Apex Finance is a student project exploring a connected process for finance promotion, file handling, email notification and data analysis.

The concept uses familiar digital tools to demonstrate how a campaign asset can move through an automated workflow, while a separate sample dataset can be explored in a business intelligence dashboard.

✳

Organised promotion

Prepare a campaign creative and export it for the next step in the process.

⌁

Automated hand-off

Illustrate how a trigger can pass a file to cloud storage and notify a team.

▤

Data-led insight

Use sample transaction data to explore products, branches and payment status.

02 — HOW IT CONNECTS
